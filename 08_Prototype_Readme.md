## Functional Prototype / MVP

### Prototype Type
Live Web Application (B2C SaaS)

### What It Demonstrates
This prototype demonstrates the core decision loop and value proposition of PrepLens AI:
1. **Contextual Matching:** Extracting requirements from a Job Description and matching them against a user's Resume.
2. **Value Hook:** Generating highly tailored, technical, and behavioral questions instantly.
3. **Monetization Workflow:** The flow where a user can purchase the full 25-question Premium Guide via Razorpay integration.

### AI Role
AI is the core engine creating value here. It performs the complex NLP task of identifying the overlap between a specific candidate's history and a specific job's requirements to generate novel questions and "Ideal Model Answers" that cannot be found via a static Google search.

### What It Does Not Yet Prove
- **Voice Analytics at Scale:** While the Voice AI mock interview feature is on the roadmap, this prototype primarily proves the *text-based* generation and the freemium conversion model. It does not yet prove the enterprise scaling economics of handling thousands of concurrent live voice sessions.
